# Tic Tac Toe

This repository contains a collection of different implementations of the classic Tic Tac Toe game.  
Each version demonstrates the same core gameplay with different technologies:

- **Tkinter (Python GUI):** A desktop version built with Python’s standard GUI library.
- **HTML / CSS / JavaScript:** A browser-based version that runs fully in the frontend.

## Purpose
The goal of this project is to showcase multiple approaches to building the same game.  
It can serve as a learning resource for comparing GUI development in Python with web development in HTML/JS/CSS.
